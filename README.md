# Miller Iberian Peninsula Adventure

Private travel diary: Spain & Portugal, May 20–31, 2026

## How to Use

### Daily Workflow (Phone or Computer)

Each evening (~10 min):

1. **Write entry:**
    - Go to `entries/` folder
    - Click **"+" → Create new file**
    - Name: `2026-05-23-valencia.md` (YYYY-MM-DD-city.md format)
    - Copy template from `entries/template-example.md`
    - Fill in: date, city, narrative, locations, food, wine, photos
    - Click **"Commit changes"**

2. **Add photos:**
    - Go to `photos/` folder (create `[city]/` subfolder if needed)
    - Click **"Add file → Upload files"**
    - Select photos from phone/computer
    - Click **"Commit changes"**

3. **Site updates automatically** ✓ (takes ~1-2 minutes)
